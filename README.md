## Run

`main.py` (Python 3.13) writes a 266-code-point text to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`). Deterministic: no network, no clock, no randomness — two runs
write the same bytes.

```
python3 main.py
```
